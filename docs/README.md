# docs/: reference

Read on demand, not every session. Search here (`grep -ri <word> docs/`) when a task touches
one of these topics.

| File | Read it when | Covers |
|---|---|---|
| [brief.md](brief.md) | any visual work | the design direction: "Hyperprint" art direction, background layers, sticker surfaces, colour, texture, typography, motion, fonts, logo, things never to do, buttons, cards, packs, game parameters |
| [pack-rip.md](pack-rip.md) | editing `pack-rip.html` | one-file rules, script order, `state` marker line, SVG size budget, code-made textures, `CHECK OK` |
| [images.md](images.md) | adding or loading images | `public/art/` and `public/textures/` paths, `ART` list, `IMG` Prelude override, file sizes, Higgsfield hand-off |
| [prompts/](prompts/README.md) | starting a numbered task | Parts 1–7: React port, Vault identity, usability, Higgsfield kit and logo, body font, Stats tab, pack animations. Written for the earlier Vault look; where a prompt and brief.md disagree on design, brief.md wins |

Texture requests live with the design work, in [`design/TEXTURES.md`](../design/TEXTURES.md).
